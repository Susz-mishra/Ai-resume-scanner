# 🚀 AI Resume Scanner - Quick Start Guide

Get your AI Resume Scanner up and running in minutes!

## ⚡ Quick Start (Windows)

1. **Double-click `start.bat`**
   - This will automatically set up everything and start the application
   - Open your browser to `http://localhost:5000`

## ⚡ Quick Start (All Platforms)

1. **Install Python 3.8+** (if not already installed)
2. **Run the startup script:**
   ```bash
   python start.py
   ```
3. **Open your browser** and go to `http://localhost:5000`

## 🧪 Test the System

Run the demo to see the AI in action:
```bash
python demo.py
```

## 📁 What You Get

- **AI Resume Analyzer**: Automatically extracts skills, experience, and contact info
- **Web Interface**: Beautiful, responsive UI for managing resumes
- **Smart Search**: Find candidates by skills, experience, or content
- **Shortlisting**: Create and manage candidate shortlists
- **Dashboard**: Analytics and insights about your resume database
- **Export**: Download data in CSV format

## 🔧 Manual Setup (if needed)

### 1. Create Virtual Environment
```bash
python -m venv venv
venv\Scripts\activate  # Windows
source venv/bin/activate  # macOS/Linux
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Start Application
```bash
python app.py
```

## 📱 Features Overview

- **Upload**: Drag & drop resumes (PDF, DOCX, DOC, TXT)
- **Analyze**: AI extracts skills, experience, education, contact info
- **Search**: Find candidates by specific criteria
- **Shortlist**: Group top candidates for different positions
- **Export**: Download shortlists and data
- **Dashboard**: View statistics and analytics
